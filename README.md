# NLP & RAG on IMDB Movie Reviews

End-to-end NLP project on 50,000 IMDB movie reviews:
- **Preprocessing:** text cleaning, normalisation and lemmatisation
- **Unsupervised learning:** topic modelling (LDA), Word2Vec, K-Means
- **Supervised learning:** sentiment classification with a classic ML model (SVM / logistic regression) and a deep-learning model, explained with LIME
- **RAG:** semantic search with sentence-transformer embeddings, answers generated by Google Gemini
- **UI:** a Streamlit app for chatting with the reviews

**Course:** ITC6110 – Natural Language Processing, Deree – The American College of Greece (Spring 2025)

## Tech
Python · NLTK · gensim · scikit-learn · TensorFlow/Keras · LIME · sentence-transformers · Google Gemini · OpenAI · Hugging Face · Streamlit

## Contents
- `NLPproj.ipynb`: main notebook (preprocessing → topic modelling → classification → XAI → RAG)
- `NLPRAG20.ipynb`: focused RAG notebook (embeddings + Gemini)
- `app2.py`: Streamlit RAG chat app (Gemini / OpenAI / Hugging Face back-ends)
- `reviews2.csv`: preprocessed subset of 5,000 reviews used by the app

## Data
`IMDB Dataset.csv` is **not included** (63 MB). Download the
[IMDB Dataset of 50K Movie Reviews](https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews)
from Kaggle and place it in the repository root.

## Setup
API keys are read from environment variables (see `.env.example`):
```powershell
$env:GOOGLE_API_KEY = "your-key"
$env:OPENAI_API_KEY = "your-key"   # optional
$env:HF_TOKEN       = "your-token" # optional
```

## How to run
```bash
pip install pandas numpy nltk gensim scikit-learn tensorflow lime sentence-transformers google-generativeai openai huggingface_hub streamlit plotly
streamlit run app2.py
```
